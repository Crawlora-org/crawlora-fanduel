# FanDuel API endpoint reference and client usage

This reference lists all 72 public FanDuel API endpoints exposed by the JavaScript/TypeScript, Python, Go, Ruby, Java, PHP, and Rust clients, including the `@crawlora-org/fanduel`, `crawlora-fanduel`, and `crawlora-fanduel` packages. The clients call Crawlora's hosted API. Set `CRAWLORA_API_KEY` to a key for your Crawlora account before making requests. Service usage is billed under that account. These clients do not run a browser or scrape FanDuel locally; Crawlora is independent from and not endorsed by FanDuel or its owners.

The package tracks the public API contract revision `sha256:cb36ab030bfb9495ece6981b47d17cda615ba7a9959a2aaaef5da0122ed79a54` bundled with release `0.1.0`. Maintainers can preview daily contract updates with the repository's `Sync live API contract` workflow; unchanged contracts do not produce package releases.

All language packages expose the selected public API operations in the bundled contract. JavaScript uses camelCase methods, Python and Rust use snake_case methods. JavaScript, Python, and Rust methods are grouped under `fanduel`; Rust uses typed parameter structs and returns the complete HTTP response.

## Client forms

- JavaScript: import `FanDuelClient` (also exported as `Client`) from `@crawlora-org/fanduel`; use `new FanDuelClient({ apiKey })` and `await client.method({ ... })`.
- Python: import `FanDuelClient` (also exported as `Client`) from `crawlora_fanduel`; use `with FanDuelClient(api_key=...) as client` and `client.method(...)`.
- Python async class: `AsyncFanDuelClient`, used with `async with` and `await`.
- Rust: add `crawlora-fanduel` with Cargo; import `Client` and the generated operation parameter struct, then call `client.fanduel.<snake_case_method>(params).await`. See the [Rust example](https://github.com/Crawlora-org/crawlora-fanduel/blob/main/rust/examples/quick_start.rs).

See the package READMEs for installation details. Keep API keys in environment variables or a secret store; do not commit them.
